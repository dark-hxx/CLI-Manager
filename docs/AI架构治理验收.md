```text
npm run check:architecture -- --strict
npm run report:architecture
```

先读相关功能入口和契约，再定位符号及依赖；不要默认加载全量翻译、CSS 或大文件。常规模块目标 400–1200 行，2000 行是硬上限。报告中的 Token 数是字节/4 的规模估算，不是计费量或实测节省比例。

Rust 检查可解析显式 crate 路径和分组导入；相对 super、局部别名和宏生成依赖仍需编译与审查。自动化通过不等于已验证所有设备和交互场景。
