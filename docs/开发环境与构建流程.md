## 2. 代码与产物分布

| 代码 | WSL 主仓库 | Windows 构建副本 |
|---|---|---|
| 源文件 (`src/`, `src-tauri/src/`) | ✅ 修改在此 | 通过 git 同步 |
| `node_modules` | ✅ Linux 版 | ✅ Windows 版 |
| `src-tauri/target` | ❌ 无（从零构建） | ✅ 5.07 GB |
| 安装包 | ❌ 不生成 | ✅ `installers/` |

> **关键**：两套 `node_modules` 不能共用。
> 平台专有二进制（esbuild、@swc/core 等）不同。

## 3. 推荐工作流

### 3.1 日常开发（WSL）

```bash
cd /mnt/demo/CLI-Manager
git status --short --branch           # 检查分支
# 修改代码...
node --test scripts/*.test.mjs        # 前端测试
npx tsc --noEmit                      # 类型检查
cd src-tauri && cargo check && cargo test   # Rust 检查
cd .. && git add . && git commit -m "feat: ..."  # 提交
git push origin <branch>              # 推送
```

### 3.2 构建 Windows 安装包（Windows）

```powershell
cd D:\Program\soft\code\CLI-Manager-src
git pull origin <branch>
npm install        # 如 package.json 有变更
npm run tauri build
# 产物:
# src-tauri\target\release\bundle\msi\
# src-tauri\target\release\bundle\nsis\
```

## 5. WSL 安装 Rust + Tauri 依赖

```bash

source "$HOME/.cargo/env"

sudo apt update
sudo apt install -y \
  libwebkit2gtk-4.1-dev \
  libappindicator3-dev \
  librsvg2-dev \
  patchelf \
  build-essential \
  curl wget file \
  libxdo-dev libssl-dev \
```

## 8. FAQ

- **WSL 和 Windows 的 node_modules 能共用？** 不能，平台二进制不同。
- **能完全在 WSL 构建 Windows 包？** 不能，需要 MSVC。
- **WSL 访问 Windows 文件？** `/mnt/d/D:/...`
- **Windows 访问 WSL 文件？** `\\wsl.localhost\Ubuntu-24.04\mnt\demo\...`
