# MCP 通用表单与平台模板设计

## Goal

让用户通过默认通用表单添加和编辑 MCP，按需选择平台模板预填配置，并通过动态参数行和名称补全减少填写成本；嵌套弹窗的键盘操作和浮层显示必须保持正确层次。

## Background

- 来源：[issue #281](https://github.com/dark-hxx/CLI-Manager/issues/281) 及本轮用户提供的三张 cc-switch 表单截图。截图用于参考布局、动态行和名称输入交互，不代表采用其中全部 CLI 或默认勾选行为。
- 用户已同意创建任务，明确要求通用表单作为默认、多个平台模板作为可选预填，并确认首批只做平台模板。
- 用户已评审下拉框方案并明确授权开始实现，指定 CHANGELOG 版本为 V1.4.4；补充要求 Esc 先关闭弹窗，弹窗关闭后下一次 Esc 才退出设置，且弹窗和菜单不能被遮挡。后续用户明确要求启动，本任务已进入 in_progress，沿用已给出的授权。
- 代码基线：按用户要求 `git pull --ff-only`，master 从 677338c5 更新至 4fbd7c03，与 origin/master 同步。
- 现有入口是单服务 JSON 编辑器；编辑器保存资源后由列表控制 CLI 选择和原生配置应用。依据 `McpEditorDialog.tsx:50`、`mcpJsonEditor.ts:36`、`GlobalMcpPanel.tsx:149`，详细发现清单见 research.md。

## Requirements

- R1：默认使用通用表单，支持 stdio / HTTP / SSE 的适用字段；保留 JSON 编辑。
- R2：模板入口使用下拉框，默认选中“通用”；选项依次为通用、百智、魔搭、Smithery、Composio，不沿用截图中的横排模板按钮。模板预填同一张表单，字段均可继续编辑；按平台真实连接/授权方式描述必填信息，不默认承诺共享凭据、免费或已验证兼容。
- R3：参数为有序可增删列表；环境变量与请求头为可增删键值对；工作目录可选。
- R4：环境变量名和请求头名称提供可自由输入的自动补全。候选优先来自模板，再来自通用列表；按用户后续反馈，环境变量中也提供 Authorization 等请求头风格名称，选择只填写当前行名称，不改变 env/headers 保存区域。
- R5：主题跟随项目现有浅色、深色与主题预设，完善键盘、焦点、滚动、窄窗口、中英文和错误状态。
- R6：沿用 MCP 资源保存、CLI 选择、显式写入原生配置的既有边界；保存资源不宣称运行会话已加载。
- R7：编辑已有资源时，保留未知扩展字段、原有身份和未修改的脱敏密钥；表单/JSON 切换不得静默丢字段。
- R8：Esc 每次只交给当前最上层交互处理：先关闭已展开的模板/补全菜单，再关闭 MCP 编辑弹窗，弹窗关闭后下一次独立按键才可退出设置。保存中或关闭确认存在时，底层不能响应；IME 组合及已被控件消费的事件不触发关闭。
- R9：设置、编辑弹窗、菜单和关闭确认按明确层级展示；菜单不被正文滚动区裁剪、不被遮罩挡住，也不能覆盖更上层确认框。Tab/Shift+Tab 保持在当前弹窗，关闭后焦点回到触发控件。

## Acceptance Criteria

- [ ] AC1：不选模板也能完整填写通用 MCP 配置，三种连接方式明确展示适用字段（R1）。
- [ ] AC2：模板下拉框默认“通用”，缩短至 240px，与表单/JSON 同行，极窄窗口可换行，支持键盘操作；至少多个平台复用同一机制，预填后可编辑，跨模板不沿用旧凭据；按最新反馈不提供模板撤销，选中项与实际草稿同步；固定值/用户专属值/授权步骤区分明确（R2）。
- [ ] AC3：动态增删后顺序、显式空值保留，半填行与重复键明确报错；新增/删除不丢焦点（R3）。
- [ ] AC4：在环境变量或请求头输入 `au` 都建议 Authorization；选择后仍保存到当前区域，不修改值。Up/Down/Enter/Escape/Tab 和 IME 行为符合 design.md §4，自定义名称可保存（R4）。
- [ ] AC5：中英文、浅深主题、大字号、800×600 小窗口均可操作；正文滚动时页脚可达、补全不裁剪，无整页横向溢出；主题/语言变化不重置草稿（R5）。
- [ ] AC6：未选 CLI 也能保存资源；保存不自动写原生配置、启动连接或重启会话；Home 变化、部分应用失败和 SSE 不兼容仍走原有保护（R6）。
- [ ] AC7：form → JSON → form 与 transport 往返不静默丢字段；无效 JSON 留在原视图；脱敏值改名要求重填，未修改原值按后端规则保留；JSON 重复键不能 last-wins（R7）。
- [ ] AC8：在设置中打开 MCP 弹窗，关闭所有菜单后按一次 Esc 只请求关闭编辑器，设置保持打开；关闭完成后再次按 Esc 才退出设置或触发既有设置离开守卫。菜单展开时 Esc 只收起菜单；保存中不关闭任何底层。普通/零时长动画、JSON 焦点、IME、重复按键和卸载后重开均验收（R8）。
- [ ] AC9：浅深主题和 800×600/150% 缩放下，模板及名称候选可见可点，靠近边缘可翻转，滚动后位置正确；确认框显示时旧菜单隐藏、编辑器停用关闭及焦点捕获，取消确认恢复编辑器；Tab/Shift+Tab 不进入设置背景（R9）。

## Out of Scope

- memory/fetch 等单个 MCP 模板、在线模板商店、平台账户中心、内置 OAuth 客户端、密钥库、自动连接测试。
- 新增粘贴 TOML/安装命令解析、一键安装链接，以及新的 CLI 支持。
- 改变数据库/IPC/schema、原生配置路径、既有应用流程或终端/Hook/项目策略。
