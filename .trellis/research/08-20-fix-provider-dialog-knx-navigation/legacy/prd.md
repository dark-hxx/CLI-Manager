# 修复供应商弹框层级与 KNX 路径跳转

## Goal

修复供应商维护界面的删除确认弹框层级，以及终端中 `/F:/.../project.knxproj` 形式的 Windows 文件路径跳转，使确认操作可见可用，文件路径打开时准确定位到实际所在目录。

## Confirmed Facts

- 用户报告供应商编辑/详情弹框中的删除确认弹框被上层弹框遮挡。
- 用户报告以 `/F:/github/.../project.knxproj` 形式出现的路径，打开后落到默认目录而不是文件所在目录。
- 发布记录版本由用户指定为 `V1.3.8`。

## Scope

- 修复供应商删除确认弹框与其父级供应商弹框的堆叠关系。
- 修复本地 Windows 驱动器绝对文件路径的检测、归一化或打开链路中造成错误目录跳转的根因。
- 为两个缺陷补充或调整聚焦回归验证；更新 `CHANGELOG.md` 与 `docs/功能清单.md`。

## Out of Scope

- 改变供应商删除权限、引用校验或删除数据语义。
- 改变 KNX 文件内容、KNX 项目解析或远程 SSH 文件浏览能力。
- 对无关弹框或所有路径协议进行重构。

## Acceptance Criteria

- [ ] 从供应商详情/编辑流程触发删除时，确认弹框始终显示在供应商弹框之上，遮罩与按钮可正常交互。
- [ ] 点击终端中的 `/F:/.../project.knxproj` 本地文件路径时，系统文件管理器定位到该文件所在目录（文件路径可被选中），不再回落到默认目录。
- [ ] 既有标准 Windows 绝对路径、UNC 路径、WSL 路径和相对路径导航不回归。
- [ ] 相关测试/类型检查通过，且发布记录使用 `V1.3.8`。
