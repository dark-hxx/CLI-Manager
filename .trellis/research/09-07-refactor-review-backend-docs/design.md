# Design

Two sequential children: audit all nine refactor commits, then document all backend methods. Previous equivalence scripts are inspected evidence, not trusted proof or migrations to rerun.

Review declarations, executable AST/tokens, import/resource resolution, state factories, React identity/lifecycle, JSX/CSS/i18n, Rust visibility and cfg branches. Investigate unexplained differences and external build/script consumers. Report introduced defects separately; no automatic repairs.

Inventory all five Cargo packages and handwritten backend scripts, including private, trait, nested, test and platform-specific methods. Exclude generated/vendor methods and anonymous closures explicitly. Add concise Chinese explanations of purpose and relevant effects/errors/concurrency; preserve useful comments. Do not generate prose by translating identifiers.

Compare executable tokens for annotation-only edits, accounting for doc attributes/macros. If comments exceed 2000 physical lines, separately audit a cohesive extraction; no compression or exemptions. Recheck GitNexus availability without permission bypass; record source-contract fallback limitations.

No app/real-service launch, push or dependency change. Validate strict architecture, frontend type/build/regressions and all affected Rust packages. Keep independent review/documentation patches, preserve unrelated work. Implementation awaits plan confirmation.
