# Web 网络配置与 Tap 项目列表修复（1.4.4）

## 需求与根因

用户切换监听网卡保存时收到 `Enable trusted network HTTP explicitly, or configure an HTTPS browser origin`。
安全校验符合现有契约；缺陷位于桌面设置的草稿/运行状态边界：必要信任选项隐藏在高级折叠区，错误直接显示后端英文，失败后的状态刷新把未保存草稿覆盖成旧配置。

用户已授权创建 task 并修复，变更记录版本为 1.4.4。
后续反馈加入：Web 设备连接填写内网 WS 地址保存提示 TLS；Tap 左侧项目列表层级异常。沿用当前任务和版本，分别验收。

## 验收

- 选择或输入非回环监听地址时展示网络信任要求并展开相关设置；HTTP 信任必须由用户显式开启。
- 保持后端 IP/Origin/HTTP 校验、HTTPS 自定义域名和反向代理行为。
- 保存失败、状态轮询/事件、启停和语言切换均不覆盖正在编辑的表单。
- 仅首次无编辑加载与成功保存同步草稿；保存期间的新编辑不被迟到结果覆盖。
- 网络信任、全部网卡缺失 Origin、无效 Origin 报错使用中英文提示。
- CHANGELOG.md 与 docs/功能清单.md 更新至现有 V1.4.4 板块。
- 设备连接在 HTTP/WS 服务地址或 HTTP 浏览器来源需要信任时展开高级配置并提供双语提示；服务与设备两开关保持独立，不自动开启。
- Tap 项目列表恢复桌面分组 parentId/groupId 与 sortOrder，同名项目以路径区分，保留不透明 ID 及会话归属。
- 新建会话使用相同的分组/排序；搜索保留祖先路径、能匹配无会话项目与分组名称；工作树会话和启动仍绑定原项目。
- 追加反馈：侧栏图标保持完整尺寸，不被长项目名或路径挤压/裁剪。默认仅展开有活跃终端的项目及其祖先分组；未选中会话时仍按当前非结束终端识别活跃项目。无活跃终端则默认全折叠，用户可手动展开/收起；搜索临时展开匹配路径，清空后恢复。

## 场景

回环 IPv4 127/8 与 IPv6；LAN/虚拟网卡/IPv6；0.0.0.0 与 ::；HTTP 未信任/显式信任；HTTPS 来源；服务停止/运行/停止中；网卡选择/手工输入；首次加载未完成/失败与重试；保存中继续编辑；轮询、事件与切换中英文。
窗口焦点、分屏、托盘、Workspan、焦点模式、WSL shell、Worktree 与 CLI Hook 不参与本机监听配置链，确认无关。
Tap 增加：嵌套/空分组、未分组项目、同名不同路径项目、交错 sortOrder、无会话项目搜索、折叠/搜索、工作树会话、SSH 禁止启动、离线、设备切换、父分组缺失/循环快照；桌面与移动抽屉共用侧栏。
