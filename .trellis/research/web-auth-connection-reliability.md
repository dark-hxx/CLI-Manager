## 验收与风险

- 隔离数据库与临时 HTTP 服务验证：首次配置、运行/停止后改密、重启不重复改密、用户名变更、旧 Cookie/移动票据撤销及设备配对保留；保留独立服务环境变量的仅首次初始化语义。
- SQLite 文件级 WAL 并发测试：认证在写锁期间仍可读，非法/过期/越权 Cookie 仍拒绝；事件清理分批、有索引，未完成转录事件不删，不影响其他操作。
- 设置页测试：仅连接后自动更新、断开/重连/配对变化同步，初次订阅与迟到请求不倒退，后台状态不覆盖未保存输入；不新增高频轮询。
- 不读取/重置用户真实密码，不重启运行中服务或终端；原生安装后的体验须由用户安装测试，不能用隔离测试冒充验收。
- 索引迁移首次执行可能延长启动；回退二进制前须备份 Web 数据库，不能直接用不认识新迁移的旧版本打开它。
