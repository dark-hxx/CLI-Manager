# 技术设计

## 边界

P0 复用旧 Web 分支已经实现的 Axum 服务、Cookie 会话、WebSocket 协议、设备身份和桌面端 Web Device Bridge。主干代码优先，冲突处保留最新数据目录、Provider、终端和设置实现，仅补入 Web 所需的公开模块、状态管理和命令注册。

## 数据流

1. 浏览器登录服务并通过配对码建立设备绑定。
2. 桌面端 `WebDeviceManager` 维护设备身份、心跳、重连和操作队列。
3. Web 服务下发 `conversation.start`/`conversation.prompt` 请求。
4. 桌面端通过原生确认后转发到现有会话/终端能力，按状态事件回传结果。
5. 浏览器仅消费脱敏后的工作区树和操作状态。

## 安全约束

- 设备凭据和配对密钥只留在桌面端与服务端存储。
- Web 协议返回项目显示信息与会话标识，不返回 Provider 密钥、环境变量和未经授权的绝对路径。
- 所有会话操作使用请求 ID/幂等键，断线重连后通过状态查询恢复，不重复执行。

## 验证

先完成合并基线构建，再按 PRD 验收命令执行服务端、前端和 Rust 检查；对失败链路补充最小回归测试。
