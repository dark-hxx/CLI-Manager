# 通用界面与终端成套配色

## 已确认范围

- 用户要求为终端和通用界面重新设计几套配色，允许借鉴主流软件。
- 用户已同意创建任务并实现，CHANGELOG 使用 TEMP。
- 新增三组、共六套明暗配色；沿用既有设置入口和主题应用流程。
- Code 深空 / 晴昼：VS Code Modern 的中性灰层次与清晰蓝色。
- Nord 极夜 / 雪原：北欧蓝灰、冰青强调色。
- Rosé 松月 / 晨曦：紫灰或暖纸背景、玫瑰与松青色点缀。
- 通用界面与终端背景、正文和强调色配套；终端提供完整 ANSI 色。
- 旧配色和默认选择兼容，自定义文字/背景设置继续覆盖预设。
- 后续用户要求：终端主题卡片固定宽度；终端外观预览扩大并展示更接近真实终端的内容。沿用本任务与 TEMP 记录。

## 实施步骤

1. 核对设置入口、主题 CSS、终端解析、持久化类型与翻译；完成 impact。
2. 添加六套 UI token、配色卡和中英文说明，补齐文字/背景对比度映射。
3. 添加六套终端预设和自动跟随映射，复用现有独立主题与预览流程。
4. 生成可直接打开的静态设计预览，用实际配色展示界面及 ANSI 日志。
5. 定向验证主题解析、明暗切换与对比度；完成前端构建和架构严格检查。
6. 更新 CHANGELOG、功能清单与任务结果。

## 场景清单

| 场景 | 验收 |
| --- | --- |
| 浅色 / 深色 / 系统切换 | 两种模式各有三套选择，终端自动模式解析到对应预设 |
| 终端独立 / 跟随应用 | 独立选择不受通用主题影响；跟随时使用成套配色 |
| 终端预览跟随 / 独立 | 与终端主题库共用预设和解析 |
| 自定义前景 / 背景图片 | 复用现有覆盖和最低对比度逻辑 |
| 已保存设置 / 重启 | 新 ID 可保存和恢复；旧 ID 与默认值不改变 |
| 多终端 / 分屏 / 失焦 / 恢复窗口 | 沿用主题订阅，人工检查既有实例换色 |
| 侧栏展开 / 折叠 / 紧凑 | 共用语义 token；窄窗卡片不溢出 |
| 中文 / 英文 | 新增标题、说明均有翻译；24 小时时制保持 |
| WSL / SSH / Worktree / Hook | 纯前端配色，无进程、协议或安装行为改动 |
