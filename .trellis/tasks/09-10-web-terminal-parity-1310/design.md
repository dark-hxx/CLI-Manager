# Design and root causes
WebTerminal scales only by width without a cap. Desktop subagent split reduces parent cols and magnifies Web text. Contain the full grid in both dimensions, capped at 1.
Web onData forwards automatic replies to live PTY even during historical replay. Desktop ConPTY DA1 differs from Web default. Establish query response ownership at the output/input boundary, never remove visible fragments as a patch.
Desktop subagents are read-only transcript pseudo-sessions, not PTYs. Transport actual content and lifecycle to a separate Web panel; do not attach a PTY to them.
Discovery: WebTerminal/styles/smoke; views/useAppModel/domain/socket; useWebDeviceBridge/webDevice; terminalStore/SubagentTranscriptView; protocol/server limits; desktop terminal output/input and ConPTY DA; release manifests. Database and installer behavior are outside scope.
Scenarios: visible/hidden/tray; split/unsplit/deep pane; active/inactive tab; multi-browser; replay/reconnect; local ConPTY/WSL; hooks enabled/disabled; worktree parent; ended/removed/unavailable transcript.
GitNexus unavailable: use refreshed memory inbound analysis plus source/contracts/tests. WebTerminal to Workbench and attachWebTerminal to command drain have CRITICAL/HIGH graph labels and require shared-path regression coverage.
Final details: actual font metrics replace CSS transform so mouse positions stay aligned. Desktop is the sole renderer-side query responder; sequence ledger distinguishes unprocessed newly-created startup output from old replay. Color query filtering retains mixed setters in stream order. Child snapshots use workspaceOnly without full history refresh; per-device latest workspace event retention bounds persisted event bodies. Device protocol4/local daemon9 require matching deployed desktop/server versions.
