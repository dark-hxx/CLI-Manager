# 移除 ccusage 支持

用户确认：删除全部 ccusage 关联代码；使用 TEMP 版本，创建任务记录。

## 范围与方案

1. 删除外部看板、store、来源类型、工具安装和 WSL 状态 UI、Rust 实现与三个 IPC 注册。
2. App 分析入口直接打开内置 StatsPanel；删除该入口专用的 Hook 检查；保留终端实时统计共用的 Hook 提示。
3. 删除偏好字段、默认值、加载规范化、同步字段和中英文文案；保留用量分析下的统计按钮可见性选项。
4. 删除仅由 ccusage 消费的 EChart 封装、专用颜色常量及 echarts/zrender 依赖。保留已发布的 v10 迁移 SQL，新增 v42 删除废弃缓存表，保证旧库升级和新库安装最终一致。
5. 更新测试、功能清单、TEMP 日志和现行契约文档。

## 场景与发现清单

- 新安装、旧设置开关 true/false、旧备份恢复：入口只依赖内置统计；旧键不再参与功能或同步。
- Windows、本地路径、WSL 单发行版/多发行版、空配置：不再检测或启动 ccusage/Bun。
- Hook 安装/未安装：分析入口均直接可用。
- 焦点、分屏、最小化、侧栏展开/收起、Workspan、Worktree、专注模式：共用 App 分析入口；保留按钮可见性与内置统计行为。
- 缓存表存在/不存在、空表/有数据：升级只删除外部报告缓存，保留历史、项目、模型价格与内置用量数据。
- 中文/英文：删除对应键并更新模型价格说明。
- 共享图表颜色、日期选择器、Hook 本体、WSL 基础能力：检查引用后保留仍有消费者的实现。

## 影响分析

App、设置页、ccusage store/面板、同步字段、模型价格页、迁移入口文件影响为 LOW。
共享 settingsStore 为 CRITICAL（114 个直接依赖、377 个影响文件），改动仅删除两个专用设置字段。
Rust ccusage 命令为 UNKNOWN，已通过字面引用确认三个 IPC 注册及前端 invoke 调用；不能将零边解释为无影响。
文件级结果没有执行流程信息，以实际 App → 看板 → store → IPC 链路补充核对。

## 复查后的测试修复

根因：Rust 的旧迁移回归测试把已发布版本 41 作为整个注册表的永久上限，新增合法的 v42 会被误判。修复位于测试断言，改为检查迁移版本严格递增，不修改生产迁移或数据库协议。

发现清单：`lib.rs` 中旧迁移测试；`app/migrations.rs` 中新增缓存清理测试；TEMP 日志与功能清单；本任务验收记录。测试通过 Rust `#[test]` 框架调用，GitNexus impact 为 UNKNOWN、无生产调用方；已按符号和测试属性核对。

新增测试覆盖：v42 唯一登记且位于 v41 之后；真实 SQLite 事务中的缺表、空表和有数据清理；表和索引删除；重复执行安全；项目、模型价格及内置用量数据保留。
