# 文件预览字体缩放与通用设置同步

## 目标

让文件预览中的文本与 Markdown 内容使用“设置 → 通用”的应用字体和应用字号，并支持在预览区域内通过 `Ctrl + 滚轮` 临时缩放字体。

## 需求

- 文本文件源码视图（Monaco）使用 `uiFontFamily` 与 `uiFontSize` 作为基础字体配置。
- Markdown 渲染预览使用同一套基础字体配置。
- 终端内的 CLI Markdown 对话预览也使用 `uiFontFamily` 与 `uiFontSize` 作为基础字体配置。
- 在文本或 Markdown 文件预览区域内：
  - `Ctrl + 向上滚轮` 放大一级；
  - `Ctrl + 向下滚轮` 缩小一级；
  - 每级为 1px，范围限制为 8px～32px；
  - 不按 `Ctrl` 时保持原有滚动行为。
- 源码视图与 Markdown 渲染预览共享当前临时缩放值；切换模式不应跳回基础字号。
- 通用设置中的字体或字号发生变化时，已打开的文件预览立即使用新基础值。
- 缩放只保留在当前文件预览组件的生命周期内，不写入通用设置，不新增持久化字段。
- 图片、无法预览的文件、Git Diff 视图不参与字体缩放。
- 终端、文件预览和终端 Markdown 预览均在首次 `Ctrl + 滚轮` 缩放后显示紧凑字号提示，显示当前字号并提供“缩小、放大、恢复”图标操作及中英文 tooltip/aria 标签；最后一次滚轮或控件操作 2 秒后自动隐藏。终端与终端 Markdown 预览的提示继承当前终端主题色。
- 终端控件复用现有终端字号设置并持久化；文件预览和终端 Markdown 预览的控件只调整当前组件的临时字号，恢复时回到各自的通用设置字号。
- 文件源码预览中的 Monaco Unicode 歧义字符提示跟随当前应用界面语言显示中文或英文，不关闭原有的 Unicode 高亮。
- 新增字号控件的中英文 i18n 文案；现有中英文界面行为保持一致。

## 场景枚举

| 维度 | 预期行为 |
| --- | --- |
| 窗口焦点 | 当前窗口内且鼠标位于文本/Markdown 预览时响应；其他窗口或应用未聚焦时不产生事件。 |
| 分屏 | 当前 pane、同窗其他 pane、深层分屏中的文件预览均由各自组件处理，不影响相邻 pane。 |
| 最小化/托盘 | 最小化期间无滚轮事件；恢复后继续使用当前通用字体配置。 |
| UI 展示模式 | 侧栏展开、折叠、紧凑模式不改变预览字体逻辑。 |
| 多会话/Workspan | 各文件预览保留自己的临时缩放；全局通用字体与字号变化对所有预览生效。 |
| 终端分屏 | Ctrl+滚轮与字号控件更新现有全局终端字号，所有终端实例一致；每个文件/Markdown 预览仍保留各自临时字号。 |
| 专注模式 | 开关专注模式不改变字体来源和缩放规则。 |
| 运行环境 | Local、WSL、Bash、SSH 的文件内容展示使用同一前端逻辑。 |
| Worktree | 主仓库、有效 Worktree、目录已缺失的 Worktree 均不引入额外路径行为；只有成功打开的内容可缩放。 |
| CLI Hook | Claude/Codex Hook 安装状态与文件预览字体无关。 |

## 验收标准

- [ ] 将通用字体切换为系统字体后，源码视图与 Markdown 预览均显示该字体。
- [ ] 将通用字号切换为 11px、13px、18px 后，已打开预览无需重启即可同步。
- [ ] `Ctrl + 滚轮` 可在 8px～32px 内逐级缩放，且阻止 WebView 页面缩放。
- [ ] 普通滚轮仍只滚动文件内容。
- [ ] 源码/预览模式切换后保留临时缩放值，通用设置本身不被修改。
- [ ] 图片、unsupported、Git Diff 的行为不变。
- [ ] 终端 Ctrl+滚轮变化后显示终端字号控件；缩小、放大和恢复按钮正常工作。
- [ ] 终端 CLI Markdown 预览跟随通用字体与字号，并提供相同的临时缩放控件。
- [ ] `npx tsc --noEmit` 与 `npm run build` 通过。
- [ ] `CHANGELOG.md` 与 `docs/功能清单.md` 按 `V1.3.6` 更新。
