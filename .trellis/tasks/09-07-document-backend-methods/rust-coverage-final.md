# Rust backend annotation coverage

## Scope proof

- `git ls-files '*.rs'` returns 268 tracked Rust files.
- The syntax-aware inventory contains 267 product Rust files and 5,930 function/method definitions, including private functions, trait methods, implementations, tests, async functions, attributes and `cfg` branches.
- The only tracked Rust file outside the inventory is `.trellis/tasks/archive/2026-09/09-07-split-rust-foundation/rust-index/src/main.rs`; it is an archived audit utility, not product/backend source.
- Ten of the 267 inventoried files contain zero function/method definitions; they remain in the inventory so zero-callable modules are not silently omitted.

The authoritative source inventory is `../09-07-audit-architecture-refactor/rust-method-inventory.json`. It was generated by the Rust syntax audit binary rather than regular-expression counts.

## Executable equivalence

`verify-comment-only.mjs` was run once across all 267 files against HEAD. Result:

```json
{"files":267,"methods":5930,"addedComments":6102,"removedBlankLines":57,"result":"comments/blank spacing only; method tokens unchanged"}
```

For every method, the verifier confirms a preceding explanation either directly before the function or before its continuous single-line attribute group. It independently compares attributes, signatures, function-body tokens and unexpanded macro tokens. Diff additions are restricted to ordinary `//` comments; the only removals are blank lines needed to retain the 2,000-line architecture limit.

The 6,102 comments exceed the 5,930 method count because useful existing comments were preserved and embedded-program functions are described from the Rust host side. No doc comment, generated string, macro input or executable token was changed.

## Runtime limits

Static token equivalence and compilation prove that annotations do not alter compiled Rust behavior, but do not prove platform runtime behavior. Real SSH, WSL, ConPTY, daemon lifecycle, credentials, installers, network access, system clipboard and GUI flows were intentionally not executed. Platform-gated macOS/Linux/Windows branches remain covered by syntax inventory and compilation where the crate configuration permits, with runtime verification deferred to their native environments.
