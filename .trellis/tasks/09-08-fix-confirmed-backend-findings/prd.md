# 修复扫描确认的后端缺陷

## Goal

为注释扫描中可由源码和隔离测试确认的逻辑错误实施根因修复与回归测试。

## Requirements

- 修复 JSON 数组和 TOML ArrayOfTables 脱敏遍历在首个命中后提前停止的问题，并覆盖多个敏感元素。
- 修复 release 运行时标记错误接纳 `runtime-state-dev.json` 的命名空间混淆。
- 修复手动热切换失败路径中故障队列恢复 future 未执行，以及回滚被未提交 journal 阻断的问题。
- 修复 Claude 模型显示名按字节截取导致非 ASCII UTF-8 边界 panic 的问题。
- 修复 Git tag format 参数、外部终端目录切换失败仍执行启动命令、文件复制/移动同源同目标先删目标等明确控制流错误。
- 修复 OpenCode 通知在请求成功前写入去重状态导致失败后重试被抑制的问题。
- 对 installer 回滚早退、共享 Hook 条目删除、Codex 布尔文本尾注释等观察先以隔离测试确认；确认后在根因层修复，不能确认则移入加固台账并说明原因。
- 每个修改符号编辑前执行 GitNexus upstream impact；HIGH/CRITICAL 风险必须在实施前明确告警。

## Acceptance Criteria

- [ ] 每个纳入项有失败回归测试或等价的确定性复现证据，修复后测试通过。
- [ ] 脱敏遍历处理所有数组/表数组元素，不泄漏后续敏感值。
- [ ] runtime marker 严格区分 debug/release 名称。
- [ ] 热切换失败恢复真实执行，journal 状态不会阻断补偿路径。
- [ ] 非 ASCII 模型名不会 panic，Git/终端/文件操作遵循既有错误与安全契约。
- [ ] 通知发送失败不会提交去重状态，后续相同状态仍可重试。
- [ ] 受影响 crate 与脚本定向测试、编译和格式化通过。

## Out of Scope

- 没有确定触发条件的容量、超时和竞态加固；这些由兄弟任务负责。
- 真实用户配置、真实远程服务或非隔离安装器操作。
