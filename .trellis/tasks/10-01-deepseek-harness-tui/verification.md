## Findings and root causes
1. Official source host 0.1.7-rc.2 rejects this local TUI 0.12.0 because two peer dependencies require 0.2.0. No compatibility exemption or user profile modification was made. Verified against an isolated compatible 0.2.0-rc.2 host instead.
2. Empty DSH_TUI_RESUME_SESSION is interpreted as an explicit invalid ID by upstream TUI. Fresh launch now actually unsets it in the selected shell; explicit IDs remain in the per-PTY environment. Stable metadata excludes this transient shell wrapper.
3. Persisted runtime bridge paths become stale after application code/hash changes. Store/sidebar now save the stable pre-overlay command; exact reserved old bridge selectors under the same manager cache parent are replaced, preserving user patches.
4. SSH projectless/custom source commands bypassed default-builder source rejection. The actual source command is rejected before remote preparation.
5. Resume command errors before the per-Tab try block could abort all restoration. Command generation now shares the per-Tab error boundary; a bad old Web script skips only its own Tab.
6. OSC bridge uses actual CLI_MANAGER_TAB_ID and foreground Channel sessionId, not Agent UUID or a shared latest pointer. Initial and A→B→A registration ownership/disposal are covered.
