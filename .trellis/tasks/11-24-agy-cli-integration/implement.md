## P5：设置 → 状态栏 → Antigravity CLI（可与 P2–P4 并行）

独立于 Hook、历史索引和 Token 取证。先用版本 1.3.5 的隔离配置验证自定义命令及叠加效果，再接现有状态栏编辑器：选择/排序显示项、样例预览、独立方案、显式应用、停用与恢复原配置。分别验证 Windows `cmd /c`、macOS/WSL `sh -c` 的可执行路径和引号；无相应环境时保留真机待验。

验收：首次打开/切换工具/预览均不运行用户已有命令、不写 agy 配置；已配置外部命令时可以取消并原样保留，能在显式替换后恢复；应用后若用户在 agy 内另改配置，撤销不得覆盖新版。相同样例的预览与实际输出一致（含 ANSI、缺字段、窄终端）；Claude、Codex 方案和其他设置不变。关闭状态栏后 Hook 与历史统计不变，开启状态栏不写历史用量。

## P0 用量取证方法

1. 只接受已标明版本及运行方式的**交互 CLI** 样本；优先取 Hook 的 `transcriptPath`，与 CLI 原生 ID 和目录核对。仅保留脱敏的字段层级、数值、事件顺序，不上传正文、邮箱、工具参数、凭据或整套用户目录。未发现样本是“未验证”，不是“不存在”。本轮仅检查命令帮助及标准根元数据；没有产生新模型调用。
2. 比较首轮、第二轮、恢复后再读和重复 step 的记录。检查每次调用的 input/output/cache/thinking 等是否存在、字段含义、是否包含缓存或思考、单位、时间与模型归属；合成夹具验证跨轮递增、合法零值、单字段缺失、重复行、压缩和版本变化。
3. 若为逐调用值，按可证明稳定的调用/步骤键去重；若为会话累计，按有序快照更新已知总量，不相加；不能正确按时间分摊的，不伪造日级趋势。费用只沿用可验证的用量及模型定价语义，未定价不宣称为零费用。不能证实的字段为未提供，不从字符串长度、工具次数、配额或上下文比例反推。
4. 若 transcript 本身不带用量，仅在同一 CLI 的受支持、可定位到同一会话的**已有结构化本地记录**有可靠证据时考虑读取；没有则按用户选择标缺失。不给状态栏装采集器，不用 headless 的输出填充既有交互历史。

## 回归与验收清单

- 分开测项目预设与手填命令、带引号路径、参数冲突、无 CLI/未登录、主目录/linked worktree/目录已失效。明确的会话目标永不自动降级成“最近会话”。
- Hook 已装/未装/禁用/冲突/桥失联、旧版与新版载荷、多窗焦点/分屏/最小化托盘、同项目双 Tab、重放及乱序、切换会话、`fullyIdle=false` 与真实失败。不改非本应用的 Hook，失败不能阻塞 agy，也不能改变审批决策。
- 历史含旧根、新根、无 workspace 映射、空/截断/追加（包括 mtime 未变而 size 增长）的 transcript；列表、搜索、详情、收藏与既有单文件删除不回归。检验有/无/部分 usage 时的侧栏、全局统计、未定价与更新速度。
- WSL：主机和两个 distro 使用相同 Linux cwd；保证配置、回调和历史均留在目标 distro 的上下文。macOS：用户 shell、bundle 引号、权限和 PATH。没有目标机器不勾选真机项；在对应 runner 或人工桌面执行。zh-CN/en-US 验证提示与 24 小时制。
