# agy CLI：项目启动、Hook、会话统计、历史与状态栏设置

## 目标与范围

在 CLI-Manager 里选用 Google Antigravity CLI，从项目或 worktree 启动、辨认当前会话状态和统计，并能从历史回到选中的同一会话。规划已获批准，按桌面版本 V1.5.3 实施。

先交付本机桌面链路。Windows 原生是当前可实测环境；**macOS 原生和 Windows 上的 WSL 是兼容要求，不是可省略的平台**。没有目标环境时，完成可移植设计、自动化契约测试和可复跑的验收步骤；只有真机通过才标记实测通过。SSH 远端桥接、独立 Web 端扩展、Antigravity App/IDE 导入、供应商管理、未经用户选择而接管状态栏、将状态栏用作历史采集器、推算账单不在本次范围。保留已有历史功能及其删除边界。

## 现状与决策

- 手填 `agy` 并非不能启动；缺的是项目预设和后续身份识别。运行命令用 `agy`，历史、Hook、统计复用 `antigravity`，不新建第二份历史源，不当作 Gemini CLI。
- Windows 本机 `agy --version` 为 **1.3.5**；`agy --help` 确认按 ID 恢复支持 `--conversation`。本轮未登录、未发模型请求、未安装 Hook。
- 现有读取器、工作区关联、基础统计和合成用例可复用；当前读取器没有提取 Token，不表示 agy 不记录它。用户决定 **先查交互日志，有可靠数据就接，没有就标缺失**。不为补数覆盖状态栏或改用 headless 模式。

## 需求与可观察的验收

| ID | 用户行为 | 验收 |
|---|---|---|
| R1 启动 | 在项目 CLI 下拉选中 Antigravity CLI，可带参数启动；已有手填命令继续工作。 | 新终端只启动一次且 cwd 正确；自定义启动命令保持优先，参数引号不变，不混入其他 CLI 的参数。找不到 agy 或未登录时能在目标终端诊断，不自动安装/提权。 |
| R2 Hook | 设置中能检查、启用、禁用、卸载 CLI-Manager 的回调；正在运行、结束和失败只落在相应 Tab。 | 同目录两个 Tab、跨窗口、分屏和 worktree 不串；恢复或 fork 后按新事件精确绑定。重复安装不重复通知，卸载保留用户条目；未装 Hook、配置冲突或桥离线不打断 agy。未证明的权限/通知事件不伪造。 |
| R3 历史 | 旧、新 CLI 会话在同一 Antigravity 来源中列出、可搜索、读详情；有效 CLI 会话可按 ID 恢复。 | 同项目先后建 A、B，从历史选 A，启动目标为 A 而非最近的 B；无有效身份、工作目录失效或来源不明时不静默切到其他会话。无 Hook 仍能读已有落盘历史；同一记录不会被算两次，旧根文件和邻接文件不改写。 |
| R4 统计 | 当前终端侧栏看本会话；全局历史分析按项目、来源、日期聚合。 | 两个会话的消息、工具和实际可用用量对得上各自详情；全局分析不依赖 Hook。区分未绑定、尚未落盘、未提供、真实 0、仅部分会话有用量；不将项目汇总冒充当前会话，不为永久缺失高频轮询，不据字符数估算。 |
| R5 平台与回归 | Windows、macOS、指定 WSL 发行版使用各自安装、配置和会话目录；切换语言时状态可读。 | Windows 完成真实端到端后才称可用；macOS/WSL 在未取得目标机器证据前单列“契约已测/真机待验”。验证 zh-CN/en-US、24 小时显示，及现有 Claude/Codex/Grok 等来源无回归。 |

**R6 · 第五项功能：agy 状态栏设置。** 在现有「设置 → 状态栏」与 Claude、Codex 并列提供 Antigravity CLI。支持独立布局与预览；用户可选 agy 默认、自定义或与默认叠加显示。已有自定义命令先展示，未经确认不替换；支持停用、恢复应用前配置。未装 Hook 也能使用，开启后不采集或回填历史 Token。验收以目标 TUI 的实际输出为准，三个工具的方案互不影响。

## 技术验证边界

默认 CLI `brain` 目录在本机存在但本轮点查有 **0 份 transcript**；未以 App 目录中的文件冒充交互式 CLI 样本。官方文档公开了日志路径以及不同接口中的用量，但未在所核对的 CLI 文档中找到逐行交互日志的 Token 契约。取得一个脱敏、注明版本的两轮 TUI 样本是实施第一步。样本不足记“未验证”；不能据此断言全版本缺失。具体取证、回退和测试见 [设计](<design.md>)、[实施与验收路线](<implement.md>)。
