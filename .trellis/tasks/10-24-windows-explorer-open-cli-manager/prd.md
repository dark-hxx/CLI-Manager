# Windows 资源管理器右键在此处打开 CLI-Manager

## Goal

让用户可以在 Windows 资源管理器中通过右键菜单，将当前目录直接作为 CLI-Manager 的普通终端工作目录打开，减少手动启动应用、切换目录和创建临时项目的步骤。

目标版本：`V1.4.5`。

## Requirements

### P0 必须支持

- 提供启动参数：`CLI-Manager.exe --open-terminal "<path>"`。
- 应用未运行时，启动应用并在指定目录创建一个普通终端标签页。
- 应用已运行时，复用现有实例，唤起并聚焦主窗口，在指定目录新建终端标签页。
- 新终端使用用户当前配置的默认 Shell，不执行 Claude、Codex 或其他 CLI 启动命令。
- 不因临时目录自动创建或持久化永久项目；终端的普通会话持久化策略保持现有设置语义。
- Windows 资源管理器同时支持文件夹本身和文件夹空白处右键菜单。
- 正确处理中文、空格、盘符根目录（例如 `C:\`）和 UNC 路径（例如 `\\server\share\repo`）。
- 右键菜单安装范围默认为当前用户（HKCU），不要求管理员权限；卸载时清理注册表项。

### P1 体验与可靠性

- 多次快速触发右键命令不得丢失路径；按触发顺序逐个创建标签页。
- 应用启动尚未完成时收到的请求必须排队，待基础初始化完成后处理。
- 创建后自动切换到终端视图并激活新标签页；窗口最小化、隐藏或不在前台时应被唤起。
- 无效、不可访问或非目录路径显示本地化错误提示，不得静默失败。
- 中英文界面均提供相关错误、状态和设置文案。

## Acceptance Criteria

- [ ] `--open-terminal` 参数解析支持独立参数形式，并拒绝空路径；可选支持 `--open-terminal=<path>` 等价形式。
- [ ] 冷启动创建一个无 `projectId`、无 `startupCmd` 的普通 PTY 会话，cwd 与 Explorer 传入目录一致。
- [ ] 已运行实例只创建一个新会话，不启动第二个 GUI 进程，并将主窗口置前聚焦。
- [ ] 文件夹右键与空白处右键分别传递 `%1` / `%V`，中文、空格、根目录、UNC 路径均能打开。
- [ ] 创建失败时返回可诊断错误并展示中英文 toast；不会留下半初始化会话或脏的永久项目记录。
- [ ] 快速连续发送至少 3 个不同目录请求，按顺序生成 3 个新标签页。
- [ ] 安装后注册表仅写入当前用户的 `Directory` 与 `Directory\Background` 菜单；卸载后键值被移除。
- [ ] Rust 参数/路径/队列单元测试、前端请求消费测试和 Windows 安装脚本静态检查通过。
- [ ] `npx tsc --noEmit`、定向 Rust 测试、`npm run check:architecture -- --strict` 通过。
- [ ] 交付实现时更新 `CHANGELOG.md` 与 `docs/功能清单.md` 的 `V1.4.5` 条目。

## Scenario Matrix

| 场景维度 | 覆盖场景 | 预期 |
|---|---|---|
| 应用生命周期 | 未启动 / 已运行 / 启动初始化中 | 冷启动创建；复用实例；请求排队后处理 |
| 窗口状态 | 前台 / 其他窗口聚焦 / 最小化 / 隐藏到托盘 | 唤起主窗口并聚焦新标签页 |
| 触发位置 | 文件夹本身 / 文件夹空白处 | 分别使用 `%1` / `%V` |
| 路径格式 | 中文 / 空格 / `C:\` / UNC / 末尾分隔符 | 保留语义，不错误截断或拆分 |
| 路径状态 | 存在目录 / 不存在 / 无权限 / 指向文件 | 目录成功；其余给出明确错误 |
| Shell | PowerShell / CMD / pwsh / Git Bash / WSL 设置 | 遵循现有默认 Shell 解析，不注入 CLI 命令 |
| 工作区 | 无项目 / 当前已有项目 / 多 Workspan 或分屏 | 临时会话不创建项目；新标签页进入当前可见工作区 |
| 并发请求 | 单次 / 连续多次 / 启动与运行切换瞬间 | 队列有序、不丢请求、不重复创建 |
| 安装状态 | 新装 / 升级 / 卸载 / 多用户 | HKCU 注册与清理，避免覆盖其他用户配置 |

## Out of Scope

- 本期不实现文件右键“打开所在目录”；可作为后续 `--open-file` 扩展。
- 本期不实现现代 Windows 11 原生 `IExplorerCommand` 菜单、图标动态化或菜单分组。
- 本期右键菜单入口以 Windows Explorer 为 P0；macOS/Linux 不强行复制 Windows 注册表方案，但 CLI 参数和应用内处理应保持跨平台可用。
- 本期不新增项目数据库字段，不改变已有终端恢复、项目识别或 Shell 选择规则。
- 本期不支持通过右键直接选择 Claude/Codex/模板命令；保留为后续动作菜单扩展。
