# Design

Node orchestrates Git source discovery. Existing TypeScript parses frontend import edges;
small conservative extractors cover CSS/Rust. Pure rule functions are independently tested.
Baseline keys exact file paths and long-line hashes so renamed/growing debt is rejected.
No build hooks or runtime app changes. New/removed/untracked files and CRLF are included.
Dependency checks only govern the new layers; legacy migration needs source review.
