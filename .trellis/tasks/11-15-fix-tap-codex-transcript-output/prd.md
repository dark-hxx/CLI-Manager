## 追加需求：Skill 补全场景

- 这是输入行为及跨层发现需求，按场景枚举与发现清单处理。
- Claude / Codex：`/` 作为网页候选入口，选中后分别填入 `/name` / `$name`；不提供内置 CLI 命令表，不因输入或发送斜杠自动切到原生面板。
- 桌面 / 手机 / IME / 长按 Enter：候选确认只填草稿，空/加载/错误候选不会误提交，发送按钮及 Ctrl/⌘+Enter 保留显式提交。
- 参数及光标：仅替换当前 token，保留光标后参数、已有 `@`、选区及长度限制；路径或句子中的斜杠不打开候选。
- 可用 / 禁用 / 被覆盖 / 无效 Skill：仅可用项成为候选；未绑定、旧设备/旧服务、错误、空结果分别显示中英文状态。
- 多账号 / 设备 / 会话 / Worktree / 分屏：当前注册根与精确 PTY/CLI 绑定，切换/隐藏/断线隔离旧请求与点击；缺失 Worktree 不读其他目录。
- 本地 / WSL / SSH / Hook：本地及 WSL 复用现有只读诊断与 guest 身份解析；SSH/伪终端保持不支持；Hook 未绑定时不借用同目录会话。
- 桌面焦点 / 托盘 / 侧栏 / focus-mode：由网页可见输入及精确主机身份决定，不靠桌面焦点发现；手动终端/直接键入入口保留。
