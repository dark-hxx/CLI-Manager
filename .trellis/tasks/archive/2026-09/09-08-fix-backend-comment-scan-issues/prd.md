# 修复桌宠 ID 路径穿越

## Goal

修复后端方法注释过程中确认的桌宠 ID 路径穿越：阻止 `.` / `..` 被当作受管理安装目录的普通 ID，避免卸载等文件操作逃逸桌宠安装根。

## Requirements

- 以 `.trellis/tasks/09-07-document-backend-methods/observations.md` 中桌宠卸载观察为问题来源，记录根因陈述、发现清单和回归测试。
- 在共享桌宠 ID 校验边界修复，不只在卸载命令症状处添加兜底。
- 修改任何函数或方法前执行 GitNexus 上游影响分析；GitNexus 不可用时记录降级依据并使用契约与定向源码检索补足触点。
- 保留当前工作区已有的大规模注释改动，不回退或覆盖其他任务成果。
- 不执行真实远程服务、真实凭据、真实用户数据库、破坏性 Git 操作或缺少隔离的危险平台测试。
- 代码变更使用 `TEMP` 更新 `CHANGELOG.md` 与 `docs/功能清单.md`。

## Acceptance Criteria

- [ ] `.`、`..` 及其首尾空白形式被桌宠 ID 校验拒绝，合法含点 ID 保持可用。
- [ ] 安装清单、目录查询、列表和卸载继续共用同一 ID 安全边界，并具有定向回归测试。
- [ ] 受影响 Rust/脚本包通过格式化、编译与定向测试。
- [ ] `npm run check:architecture -- --strict` 独立通过，未新增架构豁免或超过 2000 行的手写文件。
- [ ] GitNexus 变更检测或有记录的降级检查确认影响范围符合预期。
- [ ] `CHANGELOG.md` 和 `docs/功能清单.md` 的 `TEMP` 记录与实际修复一致。

## Out of Scope

- 本任务不处理注释扫描记录中的其他独立观察；它们需要分别分诊和验证。
- 不重构桌宠安装协议、IPC 参数或前端交互。
- 发布、提交、推送或分支同步。

## Technical Notes

- 当前分支 `refactor/ai-architecture` 没有上游，工作区在任务开始时已有约 308 项未提交改动。
- `valid_pet_id` 当前字符白名单允许单独的 `.` 和 `..`；`desktop_pet_uninstall` 随后把该值直接拼入 `installed` 根并递归删除，属于高严重级文件系统边界缺陷。
- 当前分支已先提交注释任务成果；本修复不回退该提交，也不处理无关未跟踪文件。
