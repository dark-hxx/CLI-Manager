# 项目栏添加已置顶快捷入口（issue #254）

## Goal

为项目侧边栏增加“已置顶”快捷入口。用户可以把常用项目固定到独立区域，并从该区域直接启动项目，减少在分组和终端树中查找项目的时间。

需求来源：[GitHub issue #254](https://github.com/dark-hxx/CLI-Manager/issues/254)。

## Confirmed decisions

- 本次交付版本为 V1.4.0。
- 置顶对象是项目本身，使用项目稳定 ID 关联；项目名称、路径或分组变化后，置顶关系继续保留。
- 侧边栏新增独立的“已置顶”可折叠文件夹式分组，默认展开；只有存在至少一个有效置顶项目时才显示该分组。
- 在现有项目筛选入口中增加“已置顶”选项。选择后只显示置顶项目，普通项目树隐藏。
- 置顶项目沿用现有项目的启动和终端操作能力。
- 置顶区域不参与项目树拖拽排序；新置顶项目追加到列表末尾，不在本期增加手动排序。
- 项目删除后，其置顶关系应自动清理。
- 本期不实现 issue #254 中的项目搜索；搜索状态下隐藏重复的置顶区域，避免同一项目同时出现在搜索结果和置顶区域。

## Requirements

### R1. 置顶与取消置顶

- 用户可以通过项目行的置顶操作或项目上下文菜单置顶项目。
- 已置顶项目显示取消置顶操作；取消后从“已置顶”区域移除。
- 同一个项目只能有一条置顶记录。

### R2. 已置顶区域

- 展开侧边栏时，在普通项目树上方显示“已置顶”虚拟文件夹分组；没有有效置顶项目时不渲染该分组。
- 区域标题显示 Pin 图标、文案“已置顶”、置顶项目数量和展开/收起按钮。
- 区域状态可收起并在下次启动后保持。
- 分组子项为用户选择置顶的项目，并沿用普通项目行的展示和操作。

### R3. 已置顶筛选

- 当项目筛选控件可见时，提供“全部 / 已开启 / 已置顶”三个选项；控件默认隐藏，是否展示继续由设置控制，置顶项目不会自动打开该控件。
- “已置顶”选项只显示已置顶项目；“全部”和“已开启”保留现有项目树行为，并在搜索未激活时显示置顶区域。
- 侧边栏收起时仍能识别当前筛选状态，并可切换到“已置顶”。

### R4. 启动与终端操作

- 用户可以从置顶项目行执行现有的启动操作。
- 置顶项目支持现有的基础终端操作和项目上下文操作，包括新建/打开终端、分屏（可用时）、批量选择启动、打开目录或文件等。
- 启动置顶项目时，继续使用现有的 Worktree、WSL/SSH、外部终端、Shell、CLI 参数和 hook 行为。

### R5. 项目状态与一致性

- 置顶项目使用与普通项目相同的名称、图标、终端数量、运行状态和路径提示。
- 同一项目在置顶区域和普通树中的选中状态保持一致。
- 项目重命名、移动分组、切换 Worktree 配置后，置顶入口仍指向原项目。
- 项目删除、数据恢复或同步后，不展示无法解析的置顶记录。

### R6. 侧边栏模式

- 侧边栏收起后，置顶项目以独立的快捷图标区域显示，并保留启动和上下文操作。
- 普通展开、紧凑密度、嵌入式/外置终端等现有侧边栏模式均可使用置顶入口。

### R7. 交互与可访问性

- 置顶区域可以用鼠标、键盘焦点和 Enter/Space 操作。
- 置顶按钮提供中英文 tooltip、aria-label 和状态文案。
- 置顶项目不提供拖拽移动，避免与普通树排序产生歧义。
- 置顶区域与普通树中的同一项目使用一致的选中、悬浮和焦点视觉反馈。

### R8. 国际化

- 所有新增用户可见文案同时覆盖 zh-CN 和 en-US。
- 切换界面语言后，区域标题、筛选选项、空状态、操作菜单、tooltip、aria-label 和通知均正确切换。

## Acceptance Criteria

- [ ] 常用项目可以置顶、取消置顶，刷新应用后关系仍存在。
- [ ] 有置顶项目时，侧边栏上方显示默认展开的“已置顶”文件夹式分组，支持收起、展开；没有置顶项目时不显示该分组。
- [ ] 项目筛选中可选择“已置顶”，且结果只包含置顶项目。
- [ ] 从置顶项目启动后，行为与普通项目启动完全一致，包含 Worktree、WSL/SSH、外部终端和现有终端参数处理。
- [ ] 置顶项目支持现有基础终端操作；置顶区域不能拖动排序。
- [ ] 重命名、移动分组、删除项目后，置顶入口分别保持正确关联或被清理。
- [ ] 展开与收起侧边栏、不同密度、搜索状态下没有重复或丢失的可用入口。
- [ ] 中英文界面下新增文案、tooltip、aria-label 和空状态均可用，英文时间显示不变为 12 小时制。
- [ ] npm run check:architecture -- --strict 通过且没有新增豁免。
- [ ] CHANGELOG.md 和 docs/功能清单.md 已记录 V1.4.0 的功能变更。

## Scope

### In scope

- 项目置顶关系的持久化、同步和清理。
- 独立的已置顶区域、收起状态、置顶筛选项。
- 置顶项目的启动、选中和现有基础终端操作复用。
- 展开/收起侧边栏、搜索状态、键盘和无障碍表现。
- 中英文翻译、样式、功能清单和变更日志。

### Out of scope

- 项目搜索及搜索结果排序。
- 对分组、Worktree 或单个终端建立独立置顶关系。
- 置顶项目的拖拽排序或跨分组移动。
- 修改 SQLite projects 表、Rust IPC 或新增外部依赖。
