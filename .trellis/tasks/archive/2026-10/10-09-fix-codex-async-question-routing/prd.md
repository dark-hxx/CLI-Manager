# 修复 Codex 异步 question Hook 串终端与串应用实例

## Goal
第三个终端运行、提问和完成时只更新自身状态，通知跳转到它；开发版新终端的 Hook 回到开发版。

## Requirements
- 自动启动 Codex 使用 `--no-daemon`，同时禁止启动和连接共享服务，覆盖本地、WSL、SSH、新建、分屏、Workspan 和恢复。
- 桥接启用时，新终端注入当前实例回调地址，不依赖安装健康度；创建终端不修复共享 Hook 文件。全关闭时保留 OpenCode 独立判定。
- 保留供应商参数、Hook 载荷和通知协议。要求 CLI 支持 `--no-daemon`；手工输入、自定义脚本和显式远端连接由用户管理，不宣称旧 CLI 兼容。
- 不终止既有会话；需新建 PTY 才能刷新回调环境，仅重启旧 PTY 中的 Codex 不足。CHANGELOG 版本 V1.4.3。
- 后续验收发现统计空值：已绑定 Codex UUID 的统计读取不得依赖全量历史 catalog 完成；精确定位该来源根的 rollout，保留项目和元数据身份校验。
