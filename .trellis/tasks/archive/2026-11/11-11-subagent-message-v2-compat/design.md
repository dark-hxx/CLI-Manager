# 设计与根因

## 根因陈述
转录读取/结构化解析边界没有适配 Codex v2 的 agent_message，并会丢失或覆盖首条身份元数据，因此在数据来源处修复，不能靠 UI 改标签冒充对话。

## 证据与取舍
- 截图对应日志 1,584,270 字节：首条为 child meta，第二条为继承 parent meta，含 agent_message；原解析完整/1 MiB 尾读均为 29 详情加 1 来源未知最终答复。
- 任务正文及继承 spawn_agent 参数均为加密内容。无明文时显示加密提示，不扩大到父日志订阅，不尝试解密；无法承诺还原加密任务原文。
- Rust 大文件尾读只附加首行白名单身份，字节偏移不包括合成前缀。前端裁剪同样保留精简首行，仍跳过不完整尾窗口首行。
- 解析器锁定首条身份，agent_message 依 author/recipient 与当前 agent_path 判定归属；未知/同级来源不冒充主 Agent，继承记录不提升为当前对话。
- Web v1 快照增加可选 encrypted 提示字段，旧客户端忽略；密文不进入展示快照。保持全部既有预算与只读边界。

## 发现清单
- 修改：Rust read_new_lines/首行身份、shared 解析/裁剪、terminalRuntime 追加裁剪、桌面解析窗口、Web 快照、共享 UI/双语、定向测试与契约。
- 已核对不改：普通 PTY/Hook、子线程发现与订阅命令参数、分屏关闭、Tap、历史编辑/删除、父日志读取。
- GitNexus runner 不存在（MODULE_NOT_FOUND），MCP 未暴露；降级 memory 图与契约/源码。图将共享解析器的桌面和 Web 调用方及 Rust tail_loop 标为 CRITICAL/HIGH，已向用户警示；图缺少动态 IPC 调用，以源码复核。

## 场景与回滚
- 冷读/追加/文件缩短/前部裁剪、旧/新日志、单次/多轮、父/子/同级/嵌套、明文/加密/混合、隐藏/可见、桌面/经典 Web、中英文都覆盖；本地/WSL 沿用既有文件读取，不新增扫描。
