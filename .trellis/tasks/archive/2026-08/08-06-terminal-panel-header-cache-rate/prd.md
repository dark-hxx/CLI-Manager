# 统一终端侧边栏标题与缓存命中率

## Goal

在不改变现有面板功能与文案的前提下，为终端右侧五类面板统一标题栏视觉，并在实时统计 Token 用量卡片中补充缓存命中率。

## Requirements

- 实时统计 Token 用量卡片的“缓存命中”显示紧凑 Token 数和小字号命中率，例如 `834.3K/90%`。
- 命中率口径沿用请求统计：`缓存读取 / (输入 + 缓存读取 + 缓存写入)`；分母为零时显示 `0%`，结果四舍五入为整数。
- 实时统计、文件、Git 变更、时间轴、系统资源使用同一标题栏高度、图标容器、字号、边框和背景。
- 标题栏与合并侧边面板 Tab 栏都显式使用 `TERM_PANEL.bg`，各面板保留现有强调色。
- 仅统一视觉：保留现有标题文案、项目路径、会话信息、来源徽标、本机资源徽标和操作按钮。
- 不修改后端、数据结构、依赖或国际化文案。
- Changelog Target: `[TEMP]`。

## Acceptance Criteria

- [ ] 缓存为零、无命中和正常命中时均显示正确比例，紧凑 Token 格式不变。
- [ ] 合并 Tab 与非合并并排模式下，五个标题栏的高度、背景、边框、图标和标题字号一致。
- [ ] 文件、Git、时间轴、系统资源和实时统计原有按钮及辅助信息保持可用。
- [ ] 标题栏适配现有终端侧边栏皮肤、窄宽度以及中英文界面。
- [ ] `npx tsc --noEmit` 通过，GitNexus 变更检测仅覆盖预期前端组件和文档。

## Notes

- 使用一个小型内部共享标题栏组件，避免五个面板继续复制并漂移样式。
- 不主动运行 `npm run dev/build` 或 Tauri dev/build；视觉项通过代码审查和现有运行实例可用时手工验证。
